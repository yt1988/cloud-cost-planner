    よくある質問

    おすすめはどう決めていますか？

    CPU とメモリの条件を満たすすべてのサーバープランを、各オブジェクトストレージ・CDN と組み合わせ、1 か月の費用を計算します。プラン料金、込みの転送量を超えた分（またはクラウドの GB 単位の転送料金）、ストレージ、リクエスト、CDN 転送です。全体で最安、利用者に近い中で最安、契約先が最も少ないものの 3 つを表示し、残りは比較表にあります。CDN はキャッシュヒット率 80% と仮定し、残り 20% はオリジンから取得してオリジン側のルールで課金します。

    なぜ大手クラウドはこんなに高いのですか？

    AWS、Google Cloud、Azure はインターネットへ出る 1 GB ごとに課金します（約 $0.08〜$0.12）。一方、多くの VPS は月 1〜20 TB の転送量が込みです。月に数 TB なら、転送料金がサーバー代を上回ります。

    「静的ファイル」とは？何 % にすればいい？

    どの訪問者にも同じ内容のファイル：画像、ダウンロード、動画、スクリプトなど。サーバーの代わりにストレージや CDN から配信できます。ブログはほぼ静的（約 80%）、API やプロキシは 0%、ダウンロードサイトはほぼすべて（95%）です。

    オブジェクトストレージ + CDN はいつ得ですか？

    静的ファイルが転送量の大半を占め、サーバープランの込み転送量を超えるときです。Cloudflare R2 は転送無料、Backblaze B2 も Cloudflare や Bunny 経由なら無料なので、数 TB のダウンロードが数百ドルではなく数ドルで済むこともあります。

    なぜ受信は無料で送信は有料なのですか？

    事業者は自社ネットワークから出ていく量で回線を仕入れており、受信は顧客を呼び込むため無料にしています。アップロードは無料、訪問者へのダウンロードが課金対象です。

    Google Cloud の Premium と Standard とは？

    Premium は Google のネットワークで訪問者に最も近い拠点まで運び、宛先別に課金します。Standard はデータセンター近くで一般のインターネットに渡すので安くなります。Azure の「Microsoft ネットワーク」と「インターネット」のルーティング設定も同じ考え方です。

    中国本土向けの転送はなぜ高いのですか？

    中国への国際回線は少なく高価です。Google Cloud は Premium の中国向けを別料金（通常の約 2 倍）にしており、料金に関係なく中国向けは遅いことが多いです。通常はアジア太平洋のデータセンターが最も近いので、遅延テストで確かめてください。

    性能を比べないのはなぜ？

    これは価格と仕様のフィルターで、ベンチマークではありません。共有 CPU プラン（表に表示）は近隣が混むと遅くなることがあります。気になる場合は詳細設定で除外できます。

    小さいサーバーを何台か買って転送量を稼ぐのは得？

    小さいプランを数台にしたほうが込みの転送量が多いこともあります。プランナーはその組み合わせを自動では探しません。詳細設定で台数を変えて比べてください。

    価格はどれくらい新しいですか？

    すべての価格を各社の料金ページと手作業で照合しています。確認日はフッターにあり、各行に出典リンクがあります。税抜、ユーロ価格は固定レートで換算。誤りがあれば GitHub で issue を立ててください。
