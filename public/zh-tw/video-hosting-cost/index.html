    常見問題

    推薦方案是怎麼算出來的？

    把所有符合 CPU 和記憶體需求的主機方案，與每種物件儲存、CDN 組合起來，逐一計算一個月的費用：方案價、超出方案的流量（或雲端廠商依 GB 收的對外流量費）、儲存、請求和 CDN 流量。頁面顯示整體最便宜、離使用者近的方案中最便宜、服務商最少的三個方案，其餘列在比較表。CDN 以 80% 快取命中計算，其餘 20% 回源，回源流量依來源站的規則計費。

    為什麼大型雲端廠商貴這麼多？

    AWS、Google Cloud、Azure 對流向網際網路的每 GB 都收費（約 $0.08 到 $0.12），而多數 VPS 方案每月內含 1 到 20 TB 流量。每月幾 TB 流量時，流量費比主機本身還貴。

    「靜態檔案」是什麼，該填多少？

    每位訪客拿到的都一樣的檔案：圖片、下載檔、影片、腳本。這些可以交給物件儲存或 CDN 傳送，不經過主機。部落格大多是靜態的（約 80%），API 和代理完全不是（0%），下載站幾乎全是（95%）。

    什麼時候值得用物件儲存加 CDN？

    靜態檔案占大部分流量、而且超過主機方案內含流量時。Cloudflare R2 對外流量免費，Backblaze B2 經 Cloudflare 或 Bunny 傳送也免費，幾 TB 的下載量可能只要幾美元，而不是幾百美元。

    為什麼進站免費、出站收費？

    廠商依流出自己網路的流量向上游購買頻寬，進站流量還能吸引客戶上來。所以上傳免費，送給訪客的下載流量才收費。

    Google Cloud 的 Premium 和 Standard 網路層級是什麼？

    Premium 走 Google 自己的骨幹網路，送到離訪客最近的節點再出去，依目的地計價；Standard 在機房附近就交給公共網路，比較便宜。Azure 的「Microsoft 網路」和「網際網路」路由喜好設定是同樣的概念。

    送往中國大陸的流量為什麼比較貴？

    進入中國的國際線路稀缺又昂貴。Google Cloud Premium 層級送往中國另外計價，約是一般價格的兩倍；而且不管付多少錢，進中國的線路常常都慢。通常亞太機房最近，可以先用延遲測試看看。

    為什麼不比較效能？

    這是依價格和規格篩選，不是跑分。共享 CPU 方案（表中有標註）在鄰居忙碌時可能變慢；在意的話可以在進階選項把它們排除。

    多買幾台小主機湊流量划算嗎？

    有時幾台小方案加起來的流量比一台大的多。規劃器不會自動找這種組合；可以在進階選項自己改主機數量比較。

    價格多久更新一次？

    每個價格都對照廠商官方價格頁人工核對，核對日期在頁尾，每一列都有來源連結。價格未稅，歐元價格依固定匯率換算。發現錯誤可以到 GitHub 提 issue。

    延遲是怎麼測的？到中國大陸的線路怎麼看？

    你的瀏覽器會向頁面上每個機房送出幾個小請求計時，用的是和 Me2Cloud 相同的測速點和方法：先預熱一次，再取三次的中位數。測出來的是你自己網路的真實延遲，不是實驗室數據。到中國大陸的線路品質因廠商和電信業者差異很大，價格看不出來：如果使用者在中國大陸，就在當地開啟這個頁面（或請當地使用者幫忙），比較香港和東京機房的延遲。
