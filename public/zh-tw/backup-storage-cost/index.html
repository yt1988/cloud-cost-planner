    常見問題

    推薦方案是怎麼算出來的？

    我們把所有符合你 CPU 和記憶體需求的主機方案，跟每一種物件儲存、CDN 搭配起來，逐一算出一個月的費用：方案價格、超出方案的流量費（大型雲端是按 GB 收的對外流量費）、儲存費、請求費和 CDN 流量費。頁面最多列出三種：就近機房裡最便宜的；廠商最少、帳單好管理的；以及其他地區明顯更便宜時的那一個。其餘方案都在比較表裡。使用 CDN 時，以 80% 的請求由 CDN 快取直接回應計算，另外 20% 要回源（CDN 回到你的主機或儲存空間抓檔案），這部分流量依來源端的規則計費。

    為什麼大型雲端貴這麼多？

    主要貴在流量。AWS、Google Cloud、Azure 對送往網際網路的每 GB 都收費，大約 $0.08 到 $0.12；而多數 VPS 方案每月內含 1 到 20 TB 流量。每月幾 TB 流量時，大型雲端的流量費常常比主機本身還貴。

    「靜態檔案」是什麼？要填多少？

    就是每個訪客拿到都一樣的檔案：圖片、下載檔、影片、腳本。這些可以放到物件儲存或 CDN 傳送，不經過你的主機。可以這樣估算：部落格大多是靜態的（80% 左右），API 和代理完全不是（0%），下載站幾乎全是（95%）。

    什麼時候值得用「物件儲存＋CDN」？

    靜態檔案佔了大部分流量，而且超過主機方案內含的流量時。Cloudflare R2 對外流量免費；Backblaze B2 透過 Cloudflare 或 Bunny 傳送也免費。這樣每月幾 TB 的下載，可能只要幾美元，而不是幾百美元。

    為什麼上傳免費、下載要收費？

    廠商要為流出自家網路的流量向上游購買頻寬，而流入的流量還能吸引客戶。所以你上傳到主機不用錢，主機傳給訪客的流量（對外流量）才收費。

    Google Cloud 的 Premium 級和 Standard 級差在哪？

    Premium 級先走 Google 自己的骨幹網路，到離訪客最近的節點才進入網際網路，依目的地計價；Standard 級在機房附近就交給網際網路，比較便宜。Azure 的「Microsoft 網路」和「網際網路」路由偏好也是同樣的概念。

    送往中國大陸的流量為什麼比較貴？

    因為進入中國的國際線路少、價格高。Google Cloud Premium 級送往中國另外計價，大約是一般價格的兩倍；而且不管付多少錢，進中國的線路都常常很慢。通常亞太機房最近，可以先用頁面上的延遲測試比一比。

    為什麼不比較效能？

    這裡是依價格和規格篩選，不是跑分。共用 CPU 的方案（表中有標示）在同一台實體機上的其他用戶忙碌時可能變慢。如果你在意，可以在進階選項把它們排除。

    買幾台小主機湊流量划算嗎？

    有時幾台小方案加起來的流量比一台大的還多。規劃器不會自動找這種組合，你可以在進階選項調整主機數量，自己比較看看。

    價格準確嗎？多久更新一次？

    每個價格都對照廠商官方價格頁人工核對，核對日期在頁尾，表中每一行都附來源連結。所有價格都未含營業稅、加值稅等稅費，實際帳單可能依你所在地的規定加稅。廠商以美元或歐元標價；換成其他幣別顯示時，以歐洲央行的固定參考匯率換算（日期見頁尾），和你實際被扣的金額可能略有出入。發現有錯，歡迎在 GitHub 回報 issue。

    延遲是怎麼測的？到中國大陸的線路怎麼看？

    你的瀏覽器會對頁面上每個機房送出幾個很小的請求並計時，測速點和方法跟 Me2Cloud 一樣：先暖身一次，再取三次結果的中位數。測到的是你自己網路的實際延遲，不是實驗室數據。到中國大陸的線路品質，不同廠商、不同電信業者差很多，從價格看不出來。如果你的使用者在大陸，就請在大陸開啟這個頁面（或請當地使用者幫忙開），比較香港和東京機房的延遲。
